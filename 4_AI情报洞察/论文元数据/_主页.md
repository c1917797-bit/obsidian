# 推理压缩论文元数据系统

## 系统说明

- 总论文数: **14407**
- 模板: 基于 ARS v3.6.4 literature_corpus_entry
- 字段: 包含三态阅读追踪、性能数据、个人笔记
- 数据源: arXiv (48组短语查询) + OpenReview + Papercopilot

## 文件结构

```
论文元数据/
  _主页.md (本文件)
  _索引_全部论文.md
  _未读清单.md
  参数×量化/        # 6996 篇
  参数×剪枝/        # 1722 篇
  ...
```

## 使用方式

1. **打开 `_主页.md`** - 看系统说明
2. **打开 `_索引_全部论文.md`** - 浏览所有论文
3. **打开 `_未读清单.md`** - 看待读清单
4. **进入 4×5 子目录** - 按主题精读

## 精读工作流

```
unread -> reading -> read
  ↓        ↓        ↓
首次浏览  正在读    精读完成
  ↓        ↓        ↓
           填关键创新 + 性能 + 笔记
```

## Dataview 查询示例

在主页里可加：

```dataview
TABLE cell, priority, status, year
FROM "4_AI情报洞察/论文元数据"
WHERE status = "unread"
SORT priority ASC
LIMIT 50
```
