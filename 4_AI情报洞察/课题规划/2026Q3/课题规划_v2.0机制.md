```

  综合得分 = 技术深度 × 工程影响 × 趋势强度 × 行业影响

v6.0 公式:
  综合得分（基础研究）= 50% 技术深度 + 30% 工程影响 + 10% 趋势 + 10% 行业

```

## 课题一：面向 Agent 场景的 LLM 跨轮 KV 共享机制

**研究类型**：基础研究（全新方向）
**时间窗**：P0-now（Q3 2026 必做）
**对象×方法**：K × S（KV × 稀疏化）

### v6.0 升级字段

#### 业务约束（v1.0 保留）

- Q1：✅ 多卡 MoE 架构
- Q2：✅ 128K-1M 长上下文
- Q4：✅ Agent 多轮 10-50 轮
- Q5：≤1% 精度损失
- **约束过滤**：K 必要 + 多轮场景强需求

#### 反方证据评分（v2.0 新增）

| 维度 | 评分 | 说明 |
|------|-----|------|
| 历史失败风险 | 1/3 | 类似"跨轮共享"无失败案例（全新方向） |
| 专利壁垒 | 2/3 | Prefix Caching 已有部分专利，但跨轮机制无专利 |
| 资源门槛 | 2/3 | 10-50 GPU×月（多轮评估） |
| 团队不匹配 | 2/3 | 团队 2 人有 LLM 经验，但 Agent 经验弱 |
| 反向场景 | 1/3 | 跨轮 KV 共享几乎都有价值 |
| **反方证据总分** | **8/15** | **中风险（需风险缓解）** |

**反方风险比例** = 8/15 = 53%
**修正后综合得分** = 36 × (1 - 0.53) = **16.9**（满分 36）

#### 跨格子协同分析（v2.0 新增）

```
主要格子：K×S（KV × 稀疏化）
协同格子：
  - K×G（Prefix Caching）→ 高度协同，跨轮共享是 Prefix Caching 的扩展
  - K×Q（KV 量化）→ 高度协同，跨轮共享的 KV 仍可量化
  - S×G（推理状态通用）→ 中度协同，跨轮共享类似推理状态管理

冲突格子：
  - K×P（KV 剪枝，激进）→ 低度冲突，激进剪枝后跨轮复用价值下降
  - K×Q（KV 量化，极端 1.7bps）→ 中度冲突，极端量化后跨轮复用精度损失大

协同得分：+1（与 Prefix Caching 高度协同）
```

#### 跨场景复用分析（v2.0 新增）

| 场景 | 复用度 | 说明 |
|------|-------|------|

| ASR | ❌ 不适用 | 音频流不需要"轮"概念 |
| TTS | ❌ 不适用 | 同上 |

**跨场景复用价值**：中（仅 Agent 核心，LLM 部分适用）

#### 跨场景复用调整后得分：+0%（无调整）
