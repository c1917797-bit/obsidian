# 筛选规则

## 必须追踪

- [ ] 新发布的大模型 (GPT-5, Claude 4, Gemini 2, Llama 4...)
- [ ] Agent 框架新版本 (AutoGPT, LangChain, CrewAI...)
- [ ] 推理优化技术突破 (量化、剪枝、编译优化)
- [ ] 论文影响力飙升 (引用>100 或 Twitter热议)
- [ ] 产业界大事 (融资、并购、发布)

## 观察但不急

- [ ] 产品发布但无技术创新
- [ ] 学术进展但与AI主线无关
- [ ] 二手报道（已有源发布过）

## 过滤

- [ ] 纯营销内容（无技术细节）
- [ ] 招聘帖
- [ ] 与当前研究方向无关的硬科技
- [ ] 重复报道（三天内多个源发同一件事）

## 优先级判定

| 优先级 | 条件 | 响应时效 |
|--------|------|----------|
| P0 | 新模型/框架发布、产业变革 | 24小时内 |
| P1 | 论文重要突破、工具更新 | 48小时内 |
| P2 | 技术细节、产品分析 | 本周内 |
| P3 | 行业趋势、慢讯 | 纳入周报 |

## 触发式采集规则

| 触发条件 | 采集策略 | 说明 |
| --------- | --------- | ---- |
| 大模型发布（GPT-5/Gemini 3/Claude 4） | 立即采集 + 每日跟踪 | 30分钟快讯 |
| 芯片峰会（GTC/NVIDIA发布） | 页面监控 + 3次/天 | 持续3天热点 |
| 重大投融资（>$100M） | 触发式采集 + 关联追踪 | 扩展产业链 |
| 安全漏洞/攻击事件 | 立即采集 + 每6小时跟踪 | 持续1周 |
| 开源项目版本发布 | 触发式 + release notes解析 | 一次性深度 |
| 顶会论文Accepted | 触发式 + 论文速读 | 论文质量优先 |

**触发优先级**：安全事件 > 大模型发布 > 投融资 > 峰会发布 > 版本发布
