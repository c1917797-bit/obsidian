# Obsidian 工作台质量看守

这是一层轻量质量门禁，借鉴 AgentWorkspace 的 `material-quality-guardian` 与 `workspace-temp-directory-guardian` 思路：把“资料进入知识库”变成可检查、可恢复、可追溯的流程。

## 运行

在 Obsidian 根目录或任意 PowerShell 窗口执行：

```powershell
powershell -ExecutionPolicy Bypass -File "0_Codex工作台/tools/obsidian-loop-quality.ps1" status
powershell -ExecutionPolicy Bypass -File "0_Codex工作台/tools/obsidian-loop-quality.ps1" quality
powershell -ExecutionPolicy Bypass -File "0_Codex工作台/tools/obsidian-loop-quality.ps1" report
```

## 检查范围

- `0_Codex工作台` 下的 Markdown 是否有 frontmatter 与一级标题；
- 是否存在重复标题、疑似令牌/私钥或其他敏感字段；
- 是否生成 `quality-guardian/quality-gate-state.json` 与审计报告；
- 结果为 `P0/P1/P2` 时，先在 Inbox 修复，再归档或提交。

## 与 AgentWorkspace 的边界

AgentWorkspace 负责抓取、解析、实验和生成中间产物；Obsidian 只保留人确认过的长期知识。不要把 `.tmp`、虚拟环境、缓存、下载仓库或凭据复制到知识库。
