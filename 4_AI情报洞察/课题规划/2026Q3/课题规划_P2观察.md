# 课题十九：1-bit 极限权重量化

**业务约束（业务驱动方法）**：
- Q1：✅ 多卡
- Q5：精度要求相对宽松（可接受 2-3% 损失）
- Q6：✅ 任意模型
- **约束过滤**：W 必要 + 极限压缩是远期方向

**对象×方法**：W × Q（权重 × 量化）

**观察理由**：

1. **硬件未成熟** — NVIDIA MX 格式（Microscaling Block Floating Point）尚未量产，1-bit Tensor Core 缺位
2. **软件栈不完善** — 现有推理框架（vLLM/SGLang/TensorRT-LLM）不支持 1-bit 权重的 kernel
3. **精度损失边界** — 1-bit 量化对模型精度影响大（特别是 LLM），需要 QAT + 大量训练数据
4. **2026 是早期阶段** — 学术上有 1-bit LLM 研究（如 BitNet b1.58），但工业落地零

**当前状态（2026-06）**：

| 维度 | 现状 |
|------|------|
| 学术 | BitNet b1.58 (2024) 等 5-10 篇论文 |
| 工业 | 零落地（NVIDIA MX 预计 2027 量产） |
| 框架支持 | ❌ vLLM/SGLang/TRT-LLM 均不支持 |
| 模型规模 | 仅在 1B-3B 小模型验证 |
| 精度损失 | 1B 模型 ~5%，7B 模型 ~10%+ |

**触发信号（升级到 P1）**：

```
触发条件（满足任一即升级 P1）:
  □ NVIDIA MX 格式量产（GTC 2027 发布）
  □ vLLM/SGLang 官方支持 1-bit 量化
  □ 学术突破：1-bit 7B 模型 PPL 损失 < 3%
  □ 工业巨头采用：DeepSeek/Meta 发布 1-bit 模型
  □ 客户强需求：边缘部署要求 1-bit
```

**升级决策标准**：

```
升级 P1 条件:
  AND (
    硬件支持 ✅ (NVIDIA MX 量产)
    框架支持 ✅ (vLLM 集成)
    精度可接受 ✅ (7B 模型 PPL < 3%)
    OR 客户强需求
  )
```

**跟踪信源（1_AI情报溯源）**：

```
每日:
  - NVIDIA Developer Blog (1-bit kernel 更新)
  - vLLM/SGLang Release notes (1-bit 支持)

每周:
  - arXiv cs.LG: "1-bit" "binary" "ternary" "BitNet"
  - Scholar Alert #16: LLM pruning sparse model compression
  
每月:
  - GTC 大会公告
  - NeurIPS / ICLR 论文（1-bit LLM 方向）
```

**代表论文**：
- BitNet b1.58 (2024) — 1.58-bit LLM
- BitNet (2023) — 1-bit Transformer
- OneBit (2024) — 1-bit LLM 量化
- PB-LLM (2023) — 1-bit 量化

**风险与机会**：

| 风险 | 概率 | 影响 |
|------|-----|------|
| NVIDIA MX 推迟 | 中 | 推迟 1-2 年 |
| 1-bit 精度无法达到 LLM 标准 | 高 | 方向被放弃 |
| 边缘 AI 转向专用 ASIC | 中 | 1-bit 需求下降 |

| 机会 | 概率 | 影响 |
|------|-----|------|

| 国产 GPU 抢先支持 | 中 | 国产替代机会 |

**下一步行动**：
- [ ] 每月扫描 arXiv 1-bit LLM 论文
- [ ] 跟踪 NVIDIA MX 路线图
