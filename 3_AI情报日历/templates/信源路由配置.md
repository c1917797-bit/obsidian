## 一、路由原则

```
信源层级 + 优先级  →  日报栏目  →  采集频率
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
热点资讯 P0        →  🔥 热点事件   →  每2小时
产业动态 P0        →  📊 热点方向   →  每2小时
技术动态 P0        →  💡 热点技术   →  每2小时

热点资讯 P1        →  🔥 热点事件   →  每日
产业动态 P1        →  📊 热点方向   →  每日
技术动态 P1        →  💡 热点技术   →  每日

热点资讯 P2        →  （跳过）      →  每周
产业动态 P2        →  （跳过）      →  每周
技术动态 P2        →  （跳过）      →  每周
```

## 七、采集触发规则

| 优先级 | 触发条件 | 动作 |
| ------ | -------- | ---- |
| P0 | 大模型发布（GPT-5/Gemini 3/Claude 4） | 立即采集 + 每30分钟更新直到官方确认 |
| P0 | 安全漏洞/攻击事件 | 立即采集 + 每6小时跟踪，持续1周 |
| P0 | 顶会论文Accepted | 触发式 + 论文速读 |
| P1 | 芯片峰会（GTC/NVIDIA发布） | 页面监控 + 每日3次，持续3天 |
| P1 | 重大投融资（>$100M） | 触发式采集 + 关联追踪 |
| P2 | 开源项目版本发布 | 一次性深度解析 |
