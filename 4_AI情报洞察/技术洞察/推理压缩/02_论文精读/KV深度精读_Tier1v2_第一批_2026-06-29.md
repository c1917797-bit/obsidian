## ★★★ Scaling Laws for Precision — 精度感知缩放定律

**论文**：Scaling Laws for Precision
**ID**：arXiv:2411.04330 | Kumar, Ankner, Spector 等
**机构**：Stanford + Harvard 等
**发表**：ICLR 2025 | 评分 27分（Spotlight×高引用×量化核心）

### 问题：低精度训练和推理的缩放定律缺失

```
现有缩放定律只描述 参数量→性能 关系
→ 没有考虑精度(precision)的影响
→ 无法预测：4-bit推理的损失？8-bit训练的最优参数量？
```

### 核心发现：低精度 = 有效参数量减少

```
关键洞察：
  低精度 ≠ 简单的精度损失
  低精度 = 模型的"有效参数量"减少

  effective_params = real_params × precision_factor

  → 可以用一个统一的函数形式预测：
    - 训练时低精度的损失
    - 推理时(post-training)量化的损失
    - 混合精度（不同层不同精度）的损失

  反直觉发现：
    预训练数据越多 → post-training量化退化越严重！
    → 超过阈值后，更多预训练数据对量化后性能"有害"
```

### 关键数据

| 指标 | 结果 |
|------|------|
| 验证规模 | 465个预训练run，最大1.7B参数/26B tokens |
| 核心结论 | 训练更大模型+更低精度 可以是compute-optimal |
| 反直觉发现 | 更多预训练数据 → 量化后性能更差 |

### 产业意义

- 解释了为什么大模型量化后性能下降更明显
- 指导未来模型设计：训练大模型+低精度 vs 训练小模型+高精度

## ★★★ TEAL — 全模型激活稀疏：无需训练的50%稀疏

**论文**：Training-Free Activation Sparsity in Large Language Models (TEAL)
**ID**：arXiv:2408.14690 | Liu, Ponnusamy, Cai 等
**机构**：MIT + Together AI
**发表**：ICLR 2025 Spotlight | 18分

### 问题

```
激活稀疏可以加速推理 → 但现有方法：
  - 只适用于ReLU老模型（不适用Llama-3/Mistral的SwiGLU）
  - 需要大量继续预训练（数百B tokens）
```

### TEAL方案

```
简单但有效：
  对整个模型的隐藏状态做幅度剪枝
  → 40-50%稀疏度，几乎无性能损失
  
  关键改进：
  ① 全模型稀疏（不止MLP层，hidden states也稀疏）
  ② 改进的稀疏kernel → 实际wall-clock加速（非理论FLOPs）
  ③ 与权重量化兼容 → 可叠加
```

### 关键数据

| 指标 | 结果 |
|------|------|
| 模型范围 | Llama-2/3 + Mistral, 7B-70B |
| 稀疏度 | **40-50%** |
| 解码加速 | **1.53×**（40%）/ **1.8×**（50%）|
| 训练需求 | **无** |
| 量化兼容 | ✅ |

## ★★★ SVDQuant — 低秩吸收离群值：扩散模型4-bit

**论文**：SVDQuant: Absorbing Outliers by Low-Rank Components for 4-Bit Diffusion Models
**ID**：arXiv:2411.05007 | Li, Lin, Zhang 等
**机构**：MIT-HAN-Lab
**发表**：ICLR 2025 Spotlight | 18分

### 核心创新

```
传统：smooth（离群值在权重和激活间重新分配）
SVDQuant：absorb（用低秩分支吸收离群值）

  权重 = 低秩高精度分支(SVD) + 低比特量化分支(残差)
  → 两边都更容易量化

  Nunchaku推理引擎：融合低秩+低比特kernel
  → 消除额外数据移动开销
  → 支持LoRA（无需重量化）
```

### 关键数据

| 指标 | 结果 |
|------|------|
| FLUX.1 (12B)内存 | **3.5×减少** |
| 4090 laptop INT4 | **3.0×加速** vs W4A16 |
| RTX 5090 NVFP4 | **3.1×加速** |

## ★★★ SVD-LLM — 截断感知SVD：LLM低秩压缩

**论文**：SVD-LLM: Truncation-aware Singular Value Decomposition for Large Language Model Compression
**ID**：arXiv:2403.07378 | Wang, Zheng, Wan, Zhang
**机构**：Michigan State University
**发表**：ICLR 2025 | 12分

### 问题

```
SVD压缩：截断小奇异值 → 但最小的奇异值不一定对应最小压缩损失！
现有方法：截断后不更新权重 → 精度退化
```

### 方案

```
① 截断感知数据白化：
   确保奇异值大小 ↔ 压缩损失 有直接映射关系
   → 截断最小奇异值确实最小化损失

② 序列低秩近似参数更新：
   SVD截断后 → 逐层补偿更新 → 恢复精度

→ 纯后训练（无需重训练）
```

### 关键数据

10个数据集 × 7个模型 × 3个LLM系列 × 3个规模 → 高压缩比下全面优于SOTA

## ★★★ CBQ — 跨块量化：解决块间误差累积

**论文**：CBQ: Cross-Block Quantization for Large Language Models
**ID**：arXiv:2312.07950 | Ding, Liu, Tu 等
**机构**：中科大 + 华为
**发表**：ICLR 2025 | 18分

### 问题

```
现有PTQ只处理单层/单块的离群值 → 忽略块间依赖
→ 低bit下误差累积 → 性能崩溃
```

### 方案

```
① 跨块同源重建：建立多块间的长距离依赖 → 最小化误差累积
② 粗到细预处理(CFP)：抑制权重+激活离群值
③ 自适应LoRA-Rounding：精确权重量化
```

### 关键数据

| 指标 | 结果 |
|------|------|
| 支持精度 | W4A4, W4A8, W2A16 |
| LLaMA1-65B 4-bit | **4.3小时/单GPU** |
| vs SOTA | 全面优于 |

## ★★ The Unreasonable Ineffectiveness of the Deeper Layers — 层剪枝

**论文**：The Unreasonable Ineffectiveness of the Deeper Layers
**ID**：arXiv:2403.17887 | Gromov, Tirumala, Shapourian 等
**机构**：Meta FAIR + Together AI
**发表**：ICLR 2025 | 18分

### 核心发现

```
删除深层（最多~一半）→ 性能几乎不变！
→ 深层携带的独特知识极少
→ 浅层才是知识存储的关键

方法：
  ① 层相似度分析 → 找最相似的连续层块
  ② 剪枝最相似的深层块
  ③ QLoRA"愈合"微调 → 恢复精度
```

### 关键数据

| 指标 | 结果 |
|------|------|
| 可剪枝比例 | **~50%的层** |
| 性能退化 | 极小 |
| 硬件需求 | 单40GB A100 |
