# MEMREASONER: A MEMORY-AUGMENTED LANGUAGE MODEL ARCHITECTURE FOR MULTI-HOP REASONING

**ICLR 2025** | Citations: 0 | ⏱️ 15min

## 一句话总结
MemReasoner提出了一种增强记忆的LLM架构，通过在内存中存储和推理长文档上下文，提升多跳推理能力。

## 核心贡献
1. 提出了一种新的记忆增强LLM架构MemReasoner
2. 实现了对存储在内存中的上下文进行时间推理和多步计算
3. 在128k token长度的文本上展示了更强的多跳推理能力

## 为什么重要
这项研究解决了大语言模型在处理长文档时多跳推理能力不足的问题，通过增强记忆机制提升了模型对分布式事实的推理能力，对开发更强大的生成模型具有重要意义。
