# 推理优化论文使用规范

> 确保后续所有技术洞察都基于统一论文数据库

---

## 核心原则

**所有技术分析必须从论文数据库出发，不得凭空生成。**

```
你的论文数据库（持久化在磁盘上）

┌──────────────────────────────────────────────────┐
│  inference_optimization_full.json                │
│  17,352篇 | 8个顶会录用 | 推理优化全量            │
│  ← 原始数据库，可反复用不同标准筛选               │
├──────────────────────────────────────────────────┤
│  inference_compression_v8.json                   │
│  2,555篇 | 严格推理压缩 | 2019-2026全时段        │
│  ← 压缩专用子集（Tier1/2/3分层）                 │
└──────────────────────────────────────────────────┘
```

---

## 使用方式

### 场景1：研究某个技术方向

```bash
# 查询KV Cache相关论文
python query_papers.py "KV cache"

# 查询量化论文（只看高引用）
python query_papers.py "quantization" --min-citation 20

# 查询某会议的所有压缩论文
python query_papers.py --venue "ICLR 2026" --limit 100

# 保存查询结果到Markdown
python query_papers.py "speculative decoding" --save speculative.md
```

### 场景2：更新技术地图

当技术地图需要更新时：

```bash
# 1. 查询该方向的所有论文
python query_papers.py "sparse attention" --limit 200 --save sparse.md

# 2. 基于真实论文数据更新技术地图
#    不要凭记忆/常识，必须引用数据库中的论文
```

### 场景3：发现新趋势

```bash
# 查看高引用论文（可能遗漏的里程碑）
python query_papers.py "moe" --min-citation 50

# 查看某会议的论文分布
python query_papers.py --venue "ICLR 2026" --limit 50

# 看整体统计
python query_papers.py --stats
```

### 场景4：写技术报告/精读

```
步骤：
1. python query_papers.py "你的关键词" --save 主题.md
2. 基于查询结果中的论文写精读/报告
3. 每篇引用必须能在数据库中查到
```

## 数据库结构

### inference_optimization_full.json（17,352篇）

每篇论文包含：
- title: 标题
- abstract: 摘要（前500字符）
- venue: 会议（ICLR 2025/2026, NeurIPS 2025等）
- status: 录用类型（Poster/Spotlight/Oral等）
- keywords: Papercopilot关键词
- primary_area: 主要领域
- gs_citation: Google Scholar引用数
- rating: 审稿评分
- site: OpenReview/arXiv链接
- author: 作者列表

### inference_compression_v8.json（2,555篇）

在full基础上增加：
- composite_score: 综合评分（quality×citation×relevance）
- matched_keyword: 匹配的关键词
- pipeline_source: 来源（A/classic/arxiv2026/techmap）
- tier分层: T1(≥12分)/T2(6-11)/T3(2-5)

## 数据库更新

### 每日（自动）
```bash
cd ai-intelligence-os
python main.py daily
# → 新论文自动入SQLite（不直接更新JSON）
```

### 每季度（手动）
```bash
# 1. 重新下载顶会数据
python save_full.py  # → 更新 inference_optimization_full.json

# 2. 重新筛选压缩子集
python v5_filter.py   # → 更新压缩相关论文

# 3. 合并经典+技术地图补全
python build_v6.py    # → 更新 v8语料库

# 4. 更新分层清单
python generate_tiers.py
```

---

## 禁止事项

```
❌ 不凭记忆写技术分析 → 必须先query_papers.py查数据库
❌ 不引用数据库外的论文 → 如果查不到，先补充进数据库
❌ 不使用旧版数据 → v8和full是唯一权威来源
❌ 不手动编造数字 → 统计必须从数据库计算
```
