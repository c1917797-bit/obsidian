# 必检论文核验清单

> 用途：对"必检论文"候选做逐篇身份核验，防止把预印本、未录用稿、改名稿或二手报告当作正式收录。

## 核验字段（每篇一表）

| 字段 | 核验方法 |
|---|---|
| 论文身份 | 标题 + 作者 + arXiv ID 三者一致 |
| arXiv ID | 打开 `arxiv.org/abs/<id>`，比对标题/作者 |
| 录用状态 | venue 是否为正式会议（ICLR/NeurIPS/ICML/ACL/SOSP/MLSys…）；Poster/Spotlight/Oral/Reject |
| 源码 | 是否存在可运行的公开实现（GitHub/OpenReview 附件），非"仅 README" |
| 许可证 | License 是否允许修改 + 分发 + 商业使用（Apache-2.0/MIT 优先） |
| 硬件 | 论文实验平台（GPU/NPU/ASIC），是否可迁移到 Ascend 910B4 |
| benchmark 条件 | batch/context/精度/模型规模，判定跟我们环境是否可比 |

## 裁决

| 结论 | 含义 |
|---|---|
| ✅ 通过 | 身份、录用、源码、许可证均核实，可进入源码适配审查 |
| ⚠️ 预印本 | arXiv 未录用，只能"待核验"，不能"可立项" |
| ❌ 存疑 | 标题/作者/ID 不一致，或源码缺失、许可证不允许 |
| 🚫 排除 | 违反精度约束（量化/剪枝/投机等）或硬件不匹配 |

## 批量校验命令

用 `python query_papers.py <title>` 反查数据库，或在 arXiv API 直接校验 ID：

```powershell
# 逐篇打开核对
Start-Process "https://arxiv.org/abs/<id>"
```
