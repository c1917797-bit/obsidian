

## 0. 战略导入：Agent 时代 → 分布式 AI Runtime OS 的必然演进

Agent 时代正式宣告传统 Web Serving 类推理框架进入发展瓶颈，AI Infra 从**补丁式模型服务**全面迈向**分布式 Runtime OS 新范式**。

### 0.1 Agent 范式对 AI Infra 的结构性重构

Agent 正在将 AI 系统从传统的**单轮无状态推理服务（Model Serving）**，彻底重构为：**长生命周期 + 强状态 + 动态 DAG 执行的分布式计算系统**。这一转变带来三项根本性结构异化：

- **（1）计算形态异化**
    
    从单次矩阵前向计算（Stateless Forward），转变为动态有状态图执行（Plan → Act → Reflect → Tool Call → Retry）。
    
    本质跃迁：推理系统升级为**控制与计算融合的执行引擎**，不再是单纯的模型计算服务。
    
- **（2）状态形态异化**
    
    KV Cache 从瞬时临时缓存，转变为**系统级持久驻留内存**。
    
    本质跃迁：`State ≈ OS Memory`，会话生命周期从秒级延伸至天级，状态治理成为系统核心。
    
- **（3）系统边界异化**
    
    系统从单机 / 静态并行服务，升级为跨卡、跨节点协同的分布式架构。
    
    本质跃迁：**GPU 集群被抽象为一台巨型异构计算机，Runtime 即为该集群的操作系统内核**。
    

### 0.2 核心结论

> **Agent 时代的 AI Infra 竞争，本质上不是算法层的推理优化问题，而是底层物理资源层面的分布式有状态 Runtime 操作系统问题。**

### 0.3 北极星指标：Agent Token ROI

摒弃孤立优化吞吐、延迟的思路，全栈技术统一收敛至综合效率指标：

Token ROI=GPU算力成本+KV迁移成本+分布式通信成本+跨介质Swap成本有效任务完成Token×Agent业务成功率​

**设计哲学**：所有技术选型、功能迭代，均以提升整体 Token ROI 为最终判定标准。

#### 0.6.5 五看未来（终局图景）

下一代推理系统不再是单纯的模型服务程序，而是**GPU 集群分布式 AI Runtime OS**：实现计算可编排、通信可隐藏、内存可虚拟化、会话可常驻 / 中断 / 恢复。

1. **Agent Execution Graph Compiler**：将 Agent 控制行为映射为硬件底层图原语；

3. **Cross-Layer Resource Orchestrator**：统一调度计算、显存、网络、缓存全栈资源；
4. **Cross-Tech Coordination Bus**：实现跨技术模块的时序对齐与数据流转。

## 3. 六大技术能力体系（纯技术视角・仅定义能力与机理）

> 本章为**纯技术设计**，只明确系统需要具备的能力、核心机理与解决目标，不涉及复用、自研、排期等落地内容。

### 3.1 自适应多叉树投机执行

**能力定义**：打破自回归串行限制，单步执行并行生成、批量验证多候选 Token，将串行 Decode 转为有限并行。

**核心机制**：

1. 结合 Draft 模型 / MTP 头部构建多分支候选 Token 树；
2. 主模型对整棵候选树做批量并行验证；
3. 验证失败时通过 **O(1) KV 指针重映射** 实现微秒级状态回滚，无需显存数据擦写；
4. 基于置信度动态裁剪分支，控制算力开销。
    
    **解决矛盾**：时间约束 ——Decode 串行因果律。

### 3.2 原生 MTP 流式执行

**能力定义**：基于模型原生多 Token 预测头，单次前向输出多个连续 Token，并通过时序重叠掩盖通信时延。

**核心机制**：

1. 底层硬化 MTP 并行计算图，复用前缀注意力结果，避免重复 HBM 读取；
2. 多 Token 注意力计算与卡间 NCCL 通信深度交错；
3. 分布式 TP 组间实现 Token 预算动态负载均衡。
    
    **解决矛盾**：时间约束 ——Decode 串行因果律（与投机执行形成互补）。

### 3.3 拓扑感知图同构调度

**能力定义**：让计算执行图自适应硬件通信拓扑，把任务调度至最优通信域，压缩通信开销。

**核心机制**：

1. 实时探测 NVLink/RDMA/PCIe 带宽，构建硬件通信代价拓扑图；
2. 模型计算图与硬件拓扑做**动态图同构映射**；
3. MoE 门控与高频专家就近部署在单机 NVLink 高速域；
4. 改写非阻塞集合通信原语，优化集群调度效率。
    
    **解决矛盾**：空间约束 —— 多卡通信拓扑壁垒。

### 3.4 物理级 PD 分离架构

**能力定义**：将算力密集的 Prefill 与带宽密集的 Decode 部署在物理隔离 GPU 池，彻底消除资源抢占。

**核心机制**：

1. 划分独立 Prefill 计算池、Decode 流式生成池；
2. 长文本 Prompt 分块流水线执行，平滑流量峰值；
3. 基于 **GPUDirect RDMA 零拷贝** 实现跨节点 KV Cache 传输。
    
    **解决矛盾**：空间 + 时间双重约束 ——Prefill 与 Decode 资源互锁。

### 3.5 分布式 KV-MMU 虚拟内存

**能力定义**：统一 HBM/DDR5/NVMe 三级存储编址，构建跨介质虚拟内存系统，击穿单卡显存上限。

**核心机制**：

1. 页级 KV 地址映射，实现显存碎片率归零；
2. 基于 Agent 执行状态做冷热数据识别，后台异步完成 Swap 换入 / 换出；
3. 长会话过载时自动触发快照、挂起、恢复全链路治理。
    
    **解决矛盾**：状态约束 ——KV Cache 空间膨胀。

### 3.6 集群级影子前缀缓存

**能力定义**：集群内共享公共前缀 KV 块，消除重复 Prefill 计算，用网络资源换取计算与显存空间。

**核心机制**：

1. 全局分布式 Radix Tree 前缀索引，支持跨租户、跨会话复用；
2. 本地缓存缺失时，通过 RDMA 远程直读远端 KV 块；
3. 分布式无锁缓存失效协议，保障多场景数据一致性。
    
    **解决矛盾**：状态 + 空间双重约束 —— 冗余计算与显存占用。

### 6.3 Failure Mode 工程降级矩阵（操作系统级容错）

#### 7.1 Network Degradation 网络拓扑塌方

触发条件：RDMA 网络高频丢包、带宽骤降

自愈逻辑：自动降级为单机 NVLink 域通信，跨机任务转为异步分块传输，保障执行链路不中断。

#### 7.2 Memory Explosion 显存极端过载

触发条件：HBM+DDR 同时触及物理上限

自愈逻辑：冷数据 Swap 至 NVMe → 次优先级会话快照挂起 → 资源空闲后无损恢复，逐级释放显存。

#### 7.3 Speculative Collapse 投机推理失效

触发条件：投机猜错率≥90%

自愈逻辑：微秒级熔断投机分支，退回原生单 Token 解码；后台持续监测文本熵值，场景恢复后自动重启。

#### 7.4 Scheduler Instability 分布式调度失控

触发条件：控制面时钟不同步、主控节点 CPU 过载

自愈逻辑：集群退至**单卡自治模式**，本地维持正常生成；后台热备节点接管主控，完成集群自愈。
