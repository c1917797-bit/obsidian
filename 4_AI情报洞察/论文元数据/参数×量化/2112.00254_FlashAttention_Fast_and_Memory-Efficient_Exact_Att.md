## 摘要

Transformers are slow and memory-hungry on long sequences, since the time and memory complexity of standard attention quadratic in sequence length. We propose FlashAttention, an IO-aware exact attention algorithm that is faster and memory-efficient than standard attention. We analyze the IO complexity of attention, finding that standard attention requires O(N d) memory reads/writes while FlashAttention requires O(N d) HBM accesses where N is sequence length and d is head dimension. We fuse the costly materialization of the N x N attention matrix into intermediate steps, reducing the number of reads/writes. FlashAttention trains Transformers 2x faster than the standard implementation, and enables scaling to longer sequences.
