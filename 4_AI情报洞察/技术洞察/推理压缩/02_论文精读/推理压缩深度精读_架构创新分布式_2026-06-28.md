## ★★ LCA — MLA潜空间压缩：DeepSeek架构的KV优化

**论文**：Latent-Condensed Transformer for Efficient Long Context Modeling
**ID**：arXiv:2604.12452 | ACL 2026

### 问题

DeepSeek的MLA（Multi-head Latent Attention）将KV压缩到低维潜空间，但现有稀疏注意力无法在MLA的压缩潜空间上原生操作。

### 方案

在MLA潜空间内直接压缩上下文：
- **语义潜向量**：query-aware池化聚合
- **位置Key**：锚点选择保留
- 证明长度无关的误差界

### 关键数据

| 指标 | 结果 |
|------|------|
| Prefill加速 | **2.5×** |
| KV降低 | **90%**（128K上下文）|
| 架构兼容 | MLA + GQA |
| 额外参数 | 零 |

## ★★ MAC-Attention — 计算复用：语义相似Query的注意力复用

**论文**：MAC-Attention: a Match-Amend-Complete Scheme for Fast and Accurate Attention Computation
**ID**：arXiv:2604.00235

### 核心创新

不压缩、不驱逐——**复用之前已计算的注意力**：

```
Match:   Pre-RoPE L2匹配 → 找到语义相似的近期Query
Amend:   重算匹配边界附近的小范围band → 修正边界误差
Complete: 与KV tail的新鲜注意力数值稳定合并

→ 匹配成功时计算复杂度O(1)，与上下文长度无关
```

### 关键数据

| 指标 | 结果 |
|------|------|
| KV访问减少 | **99%** |
| 128K延迟降低 | **>60%** |
| Attention加速 | **14.3×** |
| 端到端加速 | **2.6×** |
| 质量 | Full Attention级别 |

### 产业意义

开辟了"**计算复用**"轴——不压缩信息，而是避免重复计算。与所有压缩方法正交。

## ★★ DMS — 推理时超缩放：延迟驱逐的隐式合并

**论文**：Inference-Time Hyper-Scaling with KV Cache Compression
**ID**：arXiv:2506.05345 | NeurIPS 2025

### 核心洞察

```
推理时scaling的瓶颈是KV Cache大小，不是token数
→ 压缩KV → 同等计算预算下生成更多token → 推理质量提升
```

### DMS方案

**延迟驱逐 + 隐式合并**：不在token生成后立即驱逐，而是延迟 → 隐式合并表征 → 保留关键信息。

仅需**1K训练步**达到8×压缩，超越所有training-free方法。

### 关键数据

| 模型 | AIME 24 | GPQA | LiveCodeBench |
|------|---------|------|---------------|
| Qwen-R1 32B | **+12.0** | **+8.6** | **+9.7** |

## ★★ KVCapsule — VLM专用：非对称冗余压缩

**论文**：KVCapsule: Efficient Sequential KV Cache Compression for Vision-Language Models
**ID**：arXiv:2605.16439

### 核心创新

VLM的视觉token与文本token冗余模式**非对称**：
- 视觉token更长、更密集、有结构化attention模式
- LLM压缩方法直接用于VLM效果差

KVCapsule冻结VLM骨干，仅加轻量压缩/重建组件。

### 关键数据

| 指标 | 结果 |
|------|------|
| TPS提升 | **2×** |
| KV内存降低 | **2.4×**（60%压缩）|
| 精度损失 | 可忽略 |

## ★★ PolarQuant — 极坐标量化：消除归一化开销

**论文**：PolarQuant: Leveraging Polar Transformation for Key Cache Quantization
**ID**：arXiv:2502.02617

### 核心创新

将KV映射到极坐标 → 量化角度 → 角度分布有解析形式的有界分布 → **无需存储scale/zero-point**。

与QJL（消除量化常数的思路类似）方法不同但目标一致。

### 关键数据

KV压缩 **>4.2×**，长上下文评测质量最优。

## ★★ StructKV — 结构骨架：全局信息枢纽保护

**论文**：StructKV: Preserving the Structural Skeleton for Scalable Long-Context Inference
**ID**：arXiv:2604.06746 | ACL 2026 Findings

### 三重创新

1. **Global In-Degree Centrality**：跨深度聚合attention → 识别全局信息枢纽
2. **Dynamic Pivot Detection**：信息论指标自适应定位最优压缩层
3. **Structural Propagation & Decoupling**：计算预算 ≠ 内存预算（分离）

### 解决的问题

局部显著性方法在某一层pruning时，丢弃了在其他层是全局枢纽的token。StructKV捕获跨深度全局结构。

## ★★ KVSculpt — 连续空间优化：KV蒸馏

**论文**：KVSculpt: KV Cache Compression as Distillation
**ID**：arXiv:2603.27819

### 核心创新

不再选择/合并原始KV对，而是**在连续嵌入空间中优化一组无约束的KV对**：
- Key: L-BFGS优化
- Value: 闭式最小二乘解
- 交替迭代

自适应预算分配：pilot run → 按组件难度重新分配。

### 关键数据

| 指标 | 结果 |
|------|------|
| KL散度降低 | **3.5-4.1×** vs Select+Fit |
| 自适应分配增益 | **1.3×** |
| 层间MSE差异 | 高达**100×**（证明均匀分配次优）|

## ★★ BurstAttention — 双层优化：极端长序列的分布式注意力

**论文**：BurstAttention: An Efficient Distributed Attention Framework for Extremely Long Sequences
**ID**：arXiv:2403.09347

- **全局集群级**：减少跨设备通信

| 指标 | 结果 |
|------|------|
| 通信开销降低 | **40%** |
| 128K训练加速 | **1.37×**（32×A100）|

## ★★ LASP-2 — 线性注意力序列并行：一次AllGather

**论文**：LASP-2: Rethinking the Minimal Communication Requirement for Sequence Parallelism in Linear Attention Models
**ID**：arXiv:2502.07563

### 核心创新

```
传统序列并行: Ring通信（序列长度相关）
LASP:        点对点Ring（利用线性注意力的核技巧）
LASP-2:      仅需一次AllGather中间状态（大小与序列长度无关！）
             → 通信量与序列长度解耦
```

### 关键数据

| 指标 | 结果 |
|------|------|
| vs LASP | **15.2%** 更快 |
| vs Ring Attention | **36.6%** 更快 |
| 最大上下文 | 2048K（64 GPU）|
| 扩展LASP-2H | 支持线性+标准混合注意力 |

## ★★ Semantic Consensus — 行为级联邦学习：通信与模型大小解耦

**论文**：Beyond Parameter Aggregation: Semantic Consensus for Federated LLM Fine-tuning
**ID**：arXiv:2605.11857

### 核心创新

从**参数聚合**转向**行为级语义共识**：
```
传统FL: 客户端发送模型参数 → 通信量 = 模型大小
Semantic Consensus: 客户端发送生成输出 → 通信量 = prompt大小
  → 通信量与模型大小完全解耦！
  → Llama3.1-405B: 通信减少1006×
```

### 关键数据

| 模型 | 通信减少 |
|------|---------|
| Llama3.1-405B | **1006×** |
