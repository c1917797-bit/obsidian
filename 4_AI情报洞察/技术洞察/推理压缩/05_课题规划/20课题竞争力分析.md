# 20 课题竞争力分析

> 身份：AI 推理压缩技术规划师（豆包/小艺竞品背景）
> 平台：Ascend NPU（910B/910C）+ mindie
> 分析维度：3 类竞争力

---

## 第一梯队：NPU 专属壁垒（豆包做不了）

### 课题 3 — 面向多卡 MoE 的动态精度通信量化根技术

| 竞争力 | 说明 |
|--------|------|
| 硬件级 | Ascend Cube 单元原生 INT2/INT4，豆包 GPU Tensor Core INT4 效率低于 NPU |
| 华为生态 | SCD/FlexNPU/Occult 均出自华为实验室，垂直整合快 |
| 效果 | 通信量↓50-80% + 时延↓25-40% |

### 课题 17 — 面向分离式推理的跨模型 KV 迁移压缩根技术

| 竞争力 | 说明 |
|--------|------|
| 独家 | SCD（ICML 2026）+ FlexNPU 是华为系工作，豆包 GPU 无对标 |
| PD 解耦刚需 | Prefill 模型 ≠ Decode 模型，KV 不兼容是落地痛点 |
| 效果 | TTFT↓2.65x，质量损失 <5% |

### 课题 20 — 面向 NPU 原生压缩的 CANN 算子库根技术

| 竞争力 | 说明 |
|--------|------|
| 基础设施级 | 竞品有 TensorRT-LLM 统一框架，NPU 无对标 |
| 不可复制 | 竞品无法在 Cube 指令级做压缩优化（GPU 架构不具备） |
| 积累 | 前 3 年 20 个课题的算法沉淀 |

## 第二梯队：场景特化（豆包做了基础，但没做深度）

### 课题 1 — 面向多轮 Agent 的语义驱动 LLM 动态 KV 稀疏根技术

| 竞争力 | 说明 |
|--------|------|
| 场景深度 | 豆包有 KV 稀疏但聚焦通用对话，未深入 Agent 长链路 |
| 跨轮创新 | 轮次感知评分 + 跨轮共享池 + 衰减三机制联合是豆包未做的 |
| 效果 | Agent 50 轮 KV 压缩 4-8x，跨轮命中率 ≥60% |

### 课题 6 — 面向流式 ASR 的频段感知音频编码器 INT4 量化根技术

| 竞争力 | 说明 |
|--------|------|
| 频段感知 | 现有 INT8 方案不做频段差异化，WER 上升 2-3% 不可用 |
| 场景刚需 | 实时 ASR 首字<500ms 决定了语音助手可用性 |
| 效果 | 编码器加速 3-5x，Mel 频段稀疏减 20% 输入 |

### 课题 7 — 面向实时 TTS 的声码器低秩分解+蒸馏联合压缩根技术

| 竞争力 | 说明 |
|--------|------|
| 场景刚需 | 实时 TTS 数字人/有声书 First Audio<300ms 是硬指标 |
| 双路径 | 低秩分解（5x 参数↓）+ 蒸馏（MOS 保持）联合 |
| 价值 | 豆包 TTS 质量已高但用自研模型，开源生态缺这条路 |

### 课题 8 — 面向长上下文 LLM 的投机解码 KV 稀疏验证根技术

| 竞争力 | 说明 |
|--------|------|

| 硬件利用 | NPU 片上 SRAM 做冷热 KV 分层，GPU 做不了 |
| 效果 | 验证加速>20x |

### 课题 9 — 面向推理模型的 Thought 感知 KV 差异化压缩根技术

| 竞争力 | 说明 |
|--------|------|
| 前沿性 | ThinKV（ICLR 2026 Oral）+ R-KV + ShotKV，2026 最热 |
| 推理模型刚需 | DeepSeek-R1/Qwen3-thinking 必做，竞品未系统化 |
| 硬件适配 | Cube 原生 INT2/INT4 混合算力，GPU Tensor Core 无此能力 |

## 对豆包/小艺的关键差异化

| 竞品 | 我们领先的方向 |
|------|---------------|
| 豆包用全 GPU + 千卡集群 | 我们在 NPU 资源受限场景优化（边缘/小集群） |
| 豆包用自研模型 | 我们做开源模型生态（Qwen/Llama/Whisper/CosyVoice） |
| 小艺做端侧轻量化 | 我们做云端深度压缩（INT4/低秩/MLA） |
| 豆包做通用对话优化 | 我们做 Agent/推理模型/VLM 场景特化 |
| 豆包用暴力 GPU 算 | 我们用 NPU Cube INT2/INT4 原生支持 |

---

## 一句话总结

20 课题的核心竞争力 = **3 个 NPU 专属壁垒**（课题 3/17/20）+ **5 个场景特化深度**（课题 1/6/7/8/9）+ **12 个技术深度优势**。

最大的差异化是 **NPU 硬件特性 + 场景特化深度** 的结合——竞品有 GPU 资源但没有 NPU 的 Cube INT2/INT4 能力；竞品做通用优化但没做 Agent/推理模型/VLM 等场景的深度压缩。
