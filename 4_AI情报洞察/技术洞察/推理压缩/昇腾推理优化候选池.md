# 昇腾推理优化候选池

> 目标：Qwen3.5-27B（GDN 混合 48 层 + dense baseline）· Ascend 910B4 · 物理 0–3 卡 TP4
> 验收：TTFT P95 降 ≥40%、TPOT P95 降 ≥20%（目标），或按当前项目指标
> 维护规则：每次雷达新增卡 → 按本池标准初筛 → 更新候选表状态。此池是"情报 → 决策"的唯一对照表。

---

## 一、筛选标准

### A. 硬准入（GDN 项目约束，全部须满足）
1. 无损：不改权重、不重训、不量化、不删层/token、不用 MTP/投机解码、零实质精度回退
2. 昇腾适配：Ascend 910B4 / TP4 / CANN 配套版本可跑，昇腾栈无等价成熟实现
3. 工程：公开源码、可改可商用 License、独立插件可回滚
4. 证据：正式会议/官方 release 优先

### B. 架构适用性 gate（先于论文选择，来自 model-tuning-lab LESSONS_LEARNED §6.3）
1. **先证明安装模型含所需机制**：方法作用的机制（recurrent state / attention / KV / serving 层）必须真实存在于目标模型
2. **方法必须命中已观察瓶颈**：先 profile（Prefill / Decode / 通信 / 调度 哪条占关键路径），不接受"理论上有用"
3. **dense/hybrid 偏好**：dense 侧优先 exact speculative（若策略放开）、attention/KV/decode 改进、serving 层、无需重训练的 inference-time 技术；MoE 专属、diffusion、FPGA 等直接拒绝

### C. 证据与评估规则（model-tuning-lab QWEN_MODEL_SWITCH_TESTING_LESSONS + LESSONS_LEARNED）
1. **分母命名**：A/B 必须 same-denominator（如 HYPIC-only vs no-cache），不同机制分开记账（§7.1）
2. **激活证据**：配置/import 日志不足，需 planner/scheduler/worker hot-path 激活证明（§7.2）
3. **端到端测量**：理论计算削减 ≠ 端到端赢；测量整个迁移单元（§6.1）
4. **scope 分离**：implementation / operator-block / full-model 三个决策范围不得越级推广（§6.2）
5. **性能与质量是独立契约**：p95 为主指标，p50 典型，p99/max 尾部；更短输出 ≠ 更快引擎；性能与质量分阶段采样（§7.5）
6. **容量算术**：admission budget 覆盖全物理需求（private suffix / seam / block alignment / workspace）（§7.3）
7. **设备身份**：host/container NPU 映射 + TP 度是实验身份（§7.4）
8. **完成 = 独立 raw-artifact 审计**（§7.7）；operational failure ≠ algorithm failure（§7.8）
9. **生产基线隔离**：服务漂移即拒绝作 baseline，re-isolate（LESSONS_LEARNED §1.7）

## 三、验证协议（对接 model-tuning-lab 评估门禁）

1. **Gate 0 身份与环境**：冻结模型路径/checkpoint、image/vllm-ascend 版本、dtype/TP/seed/context、数据集 SHA256、endpoint、cache 隔离、NPU 分配；漂移即停
2. **Gate 1 smoke**：代表性低/高并发小样本，全完成、零错误、tokenize 一致、无 reasoning 泄漏
3. **Gate 1b warm steady-state**：未测量 warm pass，等编译/JIT（bisheng/hivmc/clang）安静后再测
4. **Gate 2 全数据集 sentinel**：一次全量（如 357 query_rewrite），报 p50/p95/p99/max TTFT/TPOT/E2E、吞吐、完成 token 分布、空输出率
5. **Gate 3 早期参考质量**：LongBench-v2 / GSM8K 等带 reference 数据集，先定 Go/No-Go
6. **Gate 4 full Go**：仅 Gate 0-3 通过者消耗全预算，1/5/8/16 ×3 重复 + 完整质量重复 + 运维稳定性

**禁止**：修改 raw 输出、SHA 漂移后重跑、无 reference 数据声称质量、单指标推荐、lab Go 后自动切生产（需 canary/A-B）。
