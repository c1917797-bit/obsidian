# Step 4：五看洞察

## 看行业（对标豆包/小艺的 8 个趋势）

### 趋势 1：全域联合优化——豆包还在单点优化

> **反直觉**：单独优化已到瓶颈。豆包用 GPU 千卡暴力算不需要联合优化，但 NPU 资源受限场景**必须联合**。

DeepSeek-V3（MLA+FP8+DeepEP 三联合）→ API $0.27/1M。HyperQuant 统一量化 1.7bps。`[实测]` Qwen-72B 联合多省 12.6%。**豆包不需要联合（有千卡），但我们需要（NPU 受限）——这就是差异化机会。**

### 趋势 2：Agent 时代——豆包做通用对话，我们做 Agent 深度

> 豆包有 KV 优化但聚焦通用对话。Agent 多轮（10-50 轮）KV 8.3x，77% 死重——**豆包未深入 Agent 长链路**。

`[内部]` Agent 第 10 轮 KV=8.3x，仅 23% 被访问。vLLM Prefix Cache（50k+star）。Models Take Notes（98.5% hit rate）。IntentKV（token 降 23.9%）。**团队已研究 H2O/Quest/R-KV/TriAttention/IceCache/IceFormer——6 个都不跨轮。**

### 趋势 3：MoE 通信——NPU Cube INT4 是 GPU 不具备的

> 豆包 GPU 通信用 NCCL（FP8），NPU 通信用 HCCL+Cube 原生 INT2/INT4。DeepEP 做了 FP8 通信但没做 INT4。

DeepEP（DeepSeek 生产级）/ FoMoE（ICLR 2026, 通信降 45x）/ ASAP（吞吐+90%）/ CloudMoE（OSDI 2026, 28 tokens/s）。`[内部]` 通信占 40-60%，87.5% 专家死重。

### 趋势 4：VLM 视觉 Token 爆炸——豆包靠 GPU 大显存扛

> 豆包有 GPU 80GB 可以全量加载 2570 视觉 Token。我们 NPU 显存受限，**必须稀疏**。

VL-Cache（90% KV↓）/ VoCo-LLaMA（576x）/ SparseVLM（动态稀疏）。

### 趋势 5：ASR 编码器 600M——豆包不做频段感知

> 豆包 ASR 用自研模型+GPU INT8。开源 Whisper INT8 WER 上升 2-3% 不可接受。

AudioKV（2026, 音频 KV 40%↓）/ ReQAT（2026, FP4 QAT）/ Distil-Whisper（3x）。

### 趋势 6：TTS 声码器——豆包用自研模型，我们做开源生态

> 豆包 TTS 用自研模型质量高。开源 HiFi-GAN 24M 占 40%+。

Vocos（参数↓80% 但 MOS 降 0.4）/ CosyVoice（多语言）。**低秩+LoRA 补偿+因果卷积流式 = 豆包未做的开源路线。**

### 趋势 7：推理模型 CoT 冗余——豆包未系统化

ThinKV（ICLR 2026 Oral, Thought 分 R/E/T 三类）/ R-KV（60-70% 不再需要）/ ShotKV（CoT 链断裂崩溃）。**竞品未系统化推理模型 KV 压缩。**

### 趋势 8：投机解码验证瓶颈——NPU SRAM 优势

Dustin（ICML 2026, 87.5% 时间在 KV 加载）。**NPU 片上 SRAM 做冷热 KV 分层，GPU 做不了——硬件级壁垒。**

## 课题 1：面向多轮 Agent 的语义驱动 LLM 动态 KV 稀疏根技术

**课题名称**：面向多轮 Agent 的语义驱动 LLM 动态 KV 稀疏根技术

**关键挑战**：DeepSeek-V3 在 128K+64 并发下 KV Cache 达 562GB（权重的 4 倍），50 轮 Agent 对话 KV 累积可达 3.5TB 导致 mindie 频繁 OOM。现有 SnapKV/H2O 只在单轮内做静态稀疏且删除后不可恢复，Agent 关键上下文被误删后任务失败率上升。`[内部]` Agent 第 10 轮 KV=8.3x，仅 23% 被后续访问（Retrieval Head ICLR 2025, 51 引用）→ 77% 死重。豆包有通用 Prefix Cache 但聚焦通用对话，未深入 Agent 长链路。团队已研究 H2O/Quest/R-KV/TriAttention/IceCache/IceFormer 六个技术，均不支持跨轮复用。

**技术目标**：对 Qwen3/Qwen2.5 系列，Agent 多轮场景：KV 压缩 4-8 倍，吞吐+40-60%，时延-20-30%，跨轮命中率≥60%。

**关键技术**：
①**基于观测窗口的语义聚类压缩（Prefill 全局瘦身）**：利用模型末尾观测窗口的注意力分布，识别每个头高关注的语义簇，仅保留聚类对应的 KV，将存储粒度从 token 级压缩为语义单元级。
创新点：在 Agent 场景工程化"语义单元级"压缩，引入跨轮语义连续性感知。借鉴 H2O 的 score 机制+Quest 的 query 感知。

②**动态渐进式 Token 选择与恢复（Decode 自适应）**：每步根据当前语义动态评估历史 Token 重要性，低贡献临时稀疏化；语义变化时允许恢复。借鉴 IceFormer 渐进淘汰+IceCache 冷热分层。
创新点：引入"可恢复稀疏"工程机制，解决永久删除导致的关键上下文丢失。

③**轮次感知 KV 评分与跨轮共享池**：每轮结束评估 KV"未来价值"，按 query 语义相似度匹配复用；轮次指数衰减(0.9^N)。借鉴 TriAttention 距离评分理论。
创新点：轮次感知评分+跨轮共享池+指数衰减三机制联合，论文界完全空白。

**技术逻辑图**：
```
[Prefill] → 观测窗口注意力 → 语义聚类 → 保留聚类KV
[Decode]  → 动态评分 → 低贡献临时稀疏 → 语义变化时恢复
[跨轮]    → 轮次评分 → 共享池匹配复用 → 指数衰减淘汰
```

**课题规划**：Agent KV 稀疏课题（语义聚类+可恢复+跨轮共享）：实现 Agent 多轮 KV 压缩 4-8 倍，跨轮命中率≥60%。

**参考论文**：
- SnapKV, NeurIPS 2024 — 观察窗口投票选 Token，本课题①聚类基础
- H2O, NeurIPS 2023 — Heavy-Hitter score，本课题①评分参考（已评估：单轮失效）
- Quest, ICLR 2025 — Query-aware top-K，本课题①query 感知（已评估：不跨轮）
- TriAttention, MIT 2026 — Pre-RoPE 三角级数距离评分，本课题③理论参考（已评估：工具调用后可能失效）
- IceCache, ICLR 2026 — 冷热分层，本课题②生命周期参考（已评估：可借鉴）
- IceFormer — 渐进淘汰，本课题②衰减参考（已评估：可借鉴）

## 课题 2：面向数学推理 LLM 的 RoPE 频域感知 KV 量化根技术

**课题名称**：面向数学推理 LLM 的 RoPE 频域感知 KV 量化根技术

**关键挑战**：所有主流 LLM 使用 RoPE 位置编码，KV 量化到 2-bit 时均匀比特分配导致 AIME 2024 数学推理直接崩溃到 0 分（FP16 基线 54.2 分），因为 RoPE 不同频域块能量差异达 10³倍。豆包用 GPU INT8 不需要 2-bit，但 NPU Cube 原生 INT2 算力是 GPU 不具备的优势——**2-bit 量化是 NPU 专属竞争力**。

**技术目标**：对 Qwen3/Llama 系列 RoPE 模型，数学推理场景：KV 压缩至 2-bit(K2V2)，AIME24≥50，通用任务精度损失≤2%，mindie 集成。

**关键技术**：
①**RoPE 频域分块+能量感知比特分配**：KV 按 RoPE 频域块分组，高能量块 4-bit，低能量 1-bit，总均 2.5-bit。利用 Ascend Cube 原生 INT2/INT4。
创新点：Block-GTQ 基础上实现频域块自适应+多模型验证+NPU 集成。

②**任务感知比特预算分配**：推理类（数学/代码）对高频敏感分配更多比特，对话类均衡。
创新点：任务类型驱动 KV 比特预算，同一框架多任务自适应。

③**mindie CANN 算子融合**：频域分块+比特分配实现为 CANN 算子，与 NPU 分页内存兼容。
创新点：RoPE 感知量化的 mindie 工业级集成，利用 Cube 原生 INT2/INT4。

**技术逻辑图**：
```
[输入KV] → RoPE频域分解 → 能量分布评估
                            ↓
          高能量块(4-bit) ← 比特分配 ← 任务类型感知
          低能量块(1-bit)
                            ↓
          [量化后KV] → CANN算子 → mindie分页内存管理
```

**课题规划**：KV 频域量化课题（RoPE 感知+任务感知+NPU 集成）：实现 KV 压缩至 2-bit，数学推理 AIME24≥50。

**参考论文**：
- Block-GTQ, 2026 — RoPE 频域块自适应，AIME24=51.7，本课题①直接基础
- OSCAR, 2026 — Attention 感知谱旋转 INT2，本课题①对比方案
- ThinKV, ICLR 2026 Oral — Thought-adaptive R/E=4bit/T=2bit，本课题②差异化参考
- KIVI, ICML 2024 — 非对称 INT2，本课题①粒度参考
- KVQuant Pre-RoPE, ICML 2024 — Pre-RoPE 消除 Key 异常值，本课题①频域理论

## 课题 3：面向多卡 MoE 的动态精度通信量化根技术

**课题名称**：面向多卡 MoE 的动态精度通信量化根技术

**关键挑战**：MoE 每个 Token 需 All-to-All 路由通信，128K+64 并发下通信占总推理时间 40-60%。DeepEP 实现 FP8 通信但未做 INT4。豆包用 GPU NCCL+千卡不需要通信压缩，但 NPU HCCS 带宽受限场景通信压缩是刚需。Ascend Cube 原生 INT4 算力是 GPU Tensor Core 不具备的。`[内部]` 通信占 40-60%，87.5% 专家死重。

**技术目标**：对 DeepSeek-V3/Qwen3-MoE，多卡推理：All-to-All 通信量降 50-80%，时延-25-40%，精度≤1%。

**关键技术**：
