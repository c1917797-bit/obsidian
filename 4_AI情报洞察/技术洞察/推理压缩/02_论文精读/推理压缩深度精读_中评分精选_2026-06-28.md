# 推理压缩论文深度精读（中评分论文精选）

> 精读时间：2026-06-28

## 一、KV驱逐/剪枝类

### LazyLLM — 动态Token剪枝：Prefill+Decode双阶段

**论文**：LazyLLM: Dynamic Token Pruning for Efficient Long Context LLM Inference
**ID**：arXiv:2407.14057 | ICLR 2025 | 评分 5.0

**核心创新**：不同于静态剪枝（一次剪完），LazyLLM允许**被剪枝的token在后续步骤重新加入**——每步动态选择不同子集。

| 指标 | 结果 |
|------|------|
| LLaMA-2-7B多文档QA Prefill加速 | **2.34×** |
| 精度 | 维持 |

---

### Ada-KV — 自适应预算：头级别驱逐

**论文**：Ada-KV: Optimizing KV Cache Eviction by Adaptive Budget Allocation
**ID**：arXiv:2407.11550

**核心创新**：建立驱逐前后attention输出的**理论上界**，证明统一预算次优 → 提出首个**头级别自适应预算分配**策略。

plug-and-play，可与SnapKV/H2O等组合。13个Ruler + 16个LongBench数据集验证显著提升。

---

### Deliberation in Latent Space — 可微缓存增强

**论文**：Deliberation in Latent Space via Differentiable Cache Augmentation
**ICLR 2025**

**核心创新**：用可微的cache augmentation在KV Cache中注入"思考"信息 → 不改变token序列但增强内部表征。Google出品。

---

### KeyDiff — Key相似度驱逐：无需注意力分数

**论文**：KeyDiff: Key Similarity-Based KV Cache Eviction
**ID**：arXiv:2504.15364

**核心创新**：完全**不依赖注意力分数**，仅用Key之间的几何相似度做驱逐。理论证明Key多样性与attention分数的关系。

| 指标 | 结果 |
|------|------|
| 8K预算（23%减少）| PPL差距 **<0.04%** |
| FlashAttention兼容 | ✅ |
| 延迟降低 | **30%** |

---

### Lexico — 稀疏编码：通用字典KV压缩

**论文**：Lexico: Extreme KV Cache Compression via Sparse Coding
**ID**：arXiv:2412.08890

**核心创新**：KV Cache可被~4K原子的**通用字典**精确稀疏近似。正交匹配 pursuit(OMP) → 灵活压缩比。

| 指标 | 结果 |
|------|------|
| KV内存 | **15-25%** |
| GSM8K性能保持 | **90-95%** |
| vs 量化/驱逐 | 更优（尤其在低内存regime） |

---

### Locret — 训练保留头：消费级GPU长上下文

**论文**：Locret: Enhancing Eviction in Long-Context LLM Inference with Trained Retaining Heads
**ID**：arXiv:2410.01805

**核心创新**：用可学习的"保留头"评估KV重要性 → 兼容chunked prefill的驱逐框架。

| 指标 | 结果 |
|------|------|
| 压缩比 | **20×**（<10%性能损失）|
| 单NVIDIA 4090 | **128K+上下文** |

---

### EMS — Evict-then-Merge：全局局部双层评分

**论文**：EMS: Adaptive Evict-then-Merge Strategy for Head-wise KV Cache Compression
**ID**：arXiv:2412.08521

**核心创新**：Global-Local Score + Evict-then-Merge框架 + 头级别并行压缩。

| 指标 | 结果 |
|------|------|
| LongBench (256 budget) | **+1.28分** |
| Needle-in-Haystack (<2% budget) | **95%检索精度** |

---

### R-KV — 冗余感知：推理模型的KV压缩

**论文**：R-KV: Redundancy-aware KV Cache Compression for Reasoning Models
**ID**：arXiv:2505.24133

**核心创新**：针对推理模型的长CoT轨迹 → 冗余感知压缩 → 10% KV保持近100%性能。

| 指标 | 结果 |
|------|------|
| KV保留 | **10%** |
| 性能保持 | **~100%** |
| 内存节省 | **90%** |
| 吞吐量 | **6.6×** |

---

## 二、KV量化类

### NestQuant — 嵌套格量化：信息论最优

**论文**：NestQuant: Nested Lattice Quantization for Matrix Products and LLMs
**ID**：arXiv:2502.09720 | ICML 2025

**核心创新**：基于自相似嵌套格（Gosset格）的PTQ方案 → 信息论最优的低精度矩阵乘。可作为任何矩阵乘步骤的drop-in量化器。

| 指标 | 结果 |
|------|------|
| 4-bit PPL (Llama-3-8B) | **6.6**（vs SpinQuant 7.3, QuaRot 8.2）|
| vs 未量化PPL | **6.14** |
| PPL差距减少 | **>55%** vs SOTA |

---

### SpinQuant — 学习旋转：量化友好的旋转变换

**论文**：SpinQuant: LLM Quantization with Learned Rotations
**ID**：arXiv:2405.16406 | ICML 2025

**核心创新**：不是随机旋转（QuaRot），而是**学习最优旋转矩阵** → 4-bit W/A/KV量化精度最大化。

| 指标 | 结果 |
|------|------|
| 4-bit gap to FP | **2.9分**（LLaMA-2-7B）|
| vs LLM-QAT | **+19.1分** |
| vs SmoothQuant | **+25.0分** |
| vs QuaRot | **减少45.1%**（LLaMA-3-8B）|

---

### PrefixQuant — 前缀离群值：静态优于动态

**论文**：PrefixQuant: Eliminating Outliers by Prefixed Tokens
**ID**：arXiv:2410.05265

**核心创新**：通过添加前缀token**消除离群值** → 静态量化优于动态量化。

W4A4KV4 和 W4A8KV4 精度均达SOTA。

---

### Qrazor — 显著数据剃刀：4-bit LLM量化

**论文**：Qrazor: Reliable and Effortless 4-bit LLM Quantization
**ID**：arXiv:2501.13331

**核心创新**：显著数据剃刀(SDR)技术 → 4-bit权重/激活/KV统一量化。

| vs SmoothQuant | **+12分** |

## 三、系统级优化

### KV-Compress — 分页KV变量压缩

**论文**：KV-Compress: Paged KV-Cache Compression with Variable Compression Rates per Attention Head
**ID**：arXiv:2410.00161

**核心创新**：兼容PagedAttention(vLLM)的KV压缩，每个attention head**独立压缩率**。

---

### SqueezeAttention — 2D KV管理：层级别最优预算

**论文**：SqueezeAttention: 2D Management of KV-Cache via Layer-wise Optimal Budget
**ID**：arXiv:2404.04793

**核心创新**：KV预算沿**序列维度+层维度**联合优化。用余弦相似度衡量层重要性。

| 指标 | 结果 |
|------|------|
| 内存减少 | **30-70%** |
| 吞吐量 | **2.2×** |

---

### Palu — 低秩投影KV压缩

**论文**：Palu: Compressing KV-Cache with Low-Rank Projection
**ID**：arXiv:2407.21118

**核心创新**：将线性层分解为低秩矩阵 → 缓存压缩的中间状态 → 推理时重建完整K/V。

| 指标 | 结果 |
|------|------|
| KV压缩 | **50%** |
| RoPE Attention加速 | **1.89×** |
| 含量化加速 | **2.91×** |

---

### Double Sparsity — 双重稀疏：Token+Channel

**论文**：Post-Training Sparse Attention with Double Sparsity
**ID**：arXiv:2408.07092

**核心创新**：Token稀疏（选重要token）+ Channel稀疏（选重要channel特征）→ 离线校准channel稀疏。

| 指标 | 结果 |
|------|------|
| Attention加速 | **14.1×** |
| 端到端加速 | **1.9×** |
| 256K解码加速 | **16.3×** |

---

### Cake — 计算+加载并行：KV Cache加载优化

**论文**：Compute Or Load KV Cache? Why Not Both?
**ID**：arXiv:2410.03065

**核心创新**：双向调度策略 → 同时利用计算和IO资源 → 自适应调度。

| 指标 | 结果 |
|------|------|
| TTFT降低 | **2.6×** |

---

### TurboRAG — 预计算KV：RAG加速

**论文**：TurboRAG: Accelerating RAG with Precomputed KV Caches
**ID**：arXiv:2410.07590

**核心创新**：离线预计算文档KV Cache → 在线直接检索已存的KV → 消除在线KV计算。

### GIST Token压缩

**论文**：A Silver Bullet or a Compromise for Full Attention? A Comprehensive Study of Gist Token-based Context Compression
**ID**：arXiv:2412.17483 | ACL 2025

**核心创新**：系统研究gist token压缩 → 识别三种失败模式：
1. **Lost by the boundary** — 边界信息丢失
2. **Lost if surprise** — 高surprisal内容丢失
3. **Lost along the way** — 长距离信息衰减

提出细粒度自编码 + 段落级重要性估计 → 缓解三种失败。

---

**论文**：KV-Distill: Nearly Lossless Context Compression for Transformers
**ID**：arXiv:2503.10337

**核心创新**：将长上下文KV蒸馏为更短表示 → KL散度匹配生成输出 → question-independent。

| 指标 | 结果 |
|------|------|
| 长度缩减 | **最高99%** |
| 精度 | 近乎无损 |
