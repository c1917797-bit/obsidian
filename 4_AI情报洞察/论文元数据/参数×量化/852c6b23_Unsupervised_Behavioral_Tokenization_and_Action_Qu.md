## 摘要

A fundamental problem in reinforcement learning is how to learn a concise discrete set of behaviors that can be easily composed to solve any downstream task. An effective "tokenization" of behavior requires tokens to be transferable, learnable in an unsupervised manner, and short-lived to facilitate composability, akin to tokens in large-language models. Previous work has studied this problem using action quantization, sub-policies, options and skills, but no solution provides an unsupervised, task-agnostic method to discover short-lived, action-spanning behavioral tokens.
