## ★★★ SageAttention — 8-bit注意力：plug-and-play推理加速

**论文**：SageAttention: Accurate 8-Bit Attention for Plug-and-play Inference Acceleration
**ID**：arXiv:2410.02367 | Zhang, Wei, Chen 等
**机构**：北大 + 字节跳动
**发表**：ICLR 2025 | 12分

### 问题

```
FP16 attention → 精度高但慢
INT8 attention → 快但精度损失（量化误差累积）
→ 需要新的量化方案
```

### 方案

```
SAGE量化：基于异常分布的per-group INT8量化
  → 比INT8高4倍精度（论文中声称）
  → 无需重新训练
  → plug-and-play（直接替换现有attention kernel）
```

### 关键数据

| 指标 | 结果 |
|------|------|
| 精度 | ~FP16级别 |
| 加速 | 8-bit比FP16快2-3× |
| 训练需求 | 无 |
| 兼容性 | 即插即用 |

## ★★ Fiddler — CPU-GPU协同MoE推理

**论文**：Fiddler: CPU-GPU Orchestration for Fast Inference of Mixture-of-Experts Models
**ID**：arXiv:2410.19259
**发表**：ICLR 2025 | 12分

### 核心方案

```
MoE推理的CPU-GPU协同：
  - Hot experts → GPU（频繁使用）
  - Cold experts → CPU（不常用）
  - 动态迁移策略
```

将MoE推理中专家的CPU-GPU分配从静态变为动态，显著提升吞吐。
