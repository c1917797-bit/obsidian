## 金字塔结构

```
                                        ┌─────────────────┐
                                        │     决策层       │
                                        └────────┬────────┘
                                                 │
               ┌────────────────────────────────┼────────────────────────────────┐
                 ▼                                ▼                                ▼
┌─────────────┐                  ┌─────────────┐                  ┌─────────────┐
          │   学术动态    │                  │   产业动态   │                  │   热点资讯   │
          │   ~35个     │                  │   70个      │                  │   36个      │
          │ 每周深度   │                  │ 每日/每周   │                  │ 每日15min │
          │ (顶会/论文) │                  │ (公司/产品) │                  │ (快讯/舆情) │
         └──────┬──────┘                  └──────┬──────┘                  └──────┬──────┘
                │                                    │                              │
                ▼                                    ▼                              ▼
         ┌─────────────┐                  ┌─────────────┐                  ┌─────────────┐
              │ 技术动态 │                      │                     │               │
              │  210个   │                      │                     │               │
              │ 每周深度 │                      │                     │               │
         └─────────────┘                       │                     │               │
                 │                             │                     │               │
                 └─────────────────────────────┴─────────────────────┘
```

**四层运转体系：**
- **热点资讯（顶层）**：每日15min快讯，核心问题——**发生了什么？**
- **产业动态（中层）**：每日标题/每周深度，核心问题——**谁在做？怎么做？**
- **学术动态**：每周深度，核心问题——**学术界有什么新突破？**
- **技术动态（底层）**：每周深度，核心问题——**为什么？原理是什么？**

## 运维规范

### 采集频率配置
| 优先级 | 采集频率 | 说明 |
| ------ | --------- | ---- |
| P0 | 每2小时 | 顶会/头部大厂/主流框架 |
| P1 | 每日 | 二线开源/中型厂商/深度博客 |
| P2 | 每周 | 小众项目/个人博客 |

### 触发式采集规则
| 触发条件 | 采集策略 | 说明 |
| --------- | --------- | ---- |
| 大模型发布（GPT-5/Gemini 3/Claude 4） | 立即采集 + 每日跟踪 | 30分钟快讯 |
| 芯片峰会（GTC/NVIDIA发布） | 页面监控 + 3次/天 | 持续3天热点 |
| 重大投融资（>$100M） | 触发式采集 + 关联追踪 | 扩展产业链 |
| 安全漏洞/攻击事件 | 立即采集 + 每6小时跟踪 | 持续1周 |

### 僵尸信源清理规则
- 连续60天无更新 → 标记为休眠
- 连续90天无更新 → 移出采集列表归档
