# When Context Leads but Parametric Memory Follows in Large Language Models

** ** | Citations: 0 | ⏱️ 30min

## 一句话总结
本文探讨了大型语言模型中上下文引导与参数化记忆之间的关系，揭示了模型如何利用上下文信息进行推理。

## 核心贡献
1. 分析了上下文引导在大型语言模型中的作用
2. 研究了参数化记忆如何跟随上下文变化
3. 提出了理解模型推理机制的新视角

## 为什么重要
这项研究有助于深入理解大型语言模型的内部工作机制，特别是上下文和记忆之间的关系，对提升模型性能和解释性具有重要意义。
