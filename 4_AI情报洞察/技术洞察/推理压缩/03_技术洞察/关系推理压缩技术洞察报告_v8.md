## 二、推理模型带来的新挑战

### KV Cache爆炸（数据库验证）

```
DeepSeek-R1生成32K+ CoT → 每步decode需加载32K KV Cache
→ 内存带宽瓶颈（不是计算瓶颈）
→ 传统KV压缩方法在长推理中失败（TriAttention论文验证）

数据库中的证据：
  TriAttention — Pre-RoPE Q/K集中 → 推理链稳定压缩
  ThinKV — 思维类型自适应 → 不同思维步骤差异化压缩
  AMS KV — Region-aware → 防止推理块整体被驱逐
  ReasonAlloc — 层级预算 → 推理模型专用分配
```
