## 一、ROI 核心公式

### 1.1 基础公式

```
ROI = (业务价值 - 投入成本) / 投入成本 × 100%

决策规则:
  ROI > 200%  → 立即立项（P0）
  ROI 100-200% → 季度内启动（P1）
  ROI 50-100%  → 观察待定（P2）
  ROI < 50%    → 暂不投入
```

### 1.2 扩展公式（含时间折现）

```
净ROI = Σ(业务价值_t / (1+r)^t) - Σ(投入成本_t / (1+r)^t)
                                                     投入成本

其中:
  t = 季度（Q1, Q2, Q3...）
  r = 折现率（建议 10%/季度 = 40%/年）
```

## 二、投入成本计算

### 2.1 GPU 成本

#### 内部集群成本

```
GPU 成本 = GPU数量 × 月数 × 单卡月成本

单卡月成本参考（2026年）:
  H100 (80GB):    ¥15,000/月   (含电费+冷却+折旧)
  H100 (80GB)云:  ¥25,000/月   (AWS p5 / 阿里云)
  A100 (80GB):    ¥8,000/月
  A100 (40GB):    ¥6,000/月
  L40S:           ¥4,000/月
  消费级 RTX 4090: ¥1,500/月   (仅研发用)
```

#### 计算示例

```
课题: K×Q 4-bit 量化部署
  训练/校准: 8 × H100 × 2周 = 8 × 15000 × 0.5 = ¥60,000
  推理测试: 4 × H100 × 4周 = 4 × 15000 × 1.0 = ¥60,000
  合计 GPU 成本 = ¥120,000
```

### 2.2 人力成本

```
人力成本 = Σ(人数 × 月数 × 人均月成本)

人均月成本参考（2026年，含五险一金）:
  资深算法工程师:   ¥40,000/月
  中级算法工程师:   ¥25,000/月
  初级工程师:       ¥15,000/月
  工程实施:         ¥20,000/月
  研究实习生:       ¥8,000/月
```

#### 计算示例

```
课题: K×Q 4-bit 量化部署
  资深算法 × 1 × 3月 = 40,000 × 3 = ¥120,000
  工程实施 × 1 × 2月 = 20,000 × 2 = ¥40,000
  实习生 × 1 × 3月   = 8,000 × 3  = ¥24,000
  合计人力成本 = ¥184,000
```

### 2.3 其他成本

```
其他成本 = 数据采购 + API调用 + 会议差旅 + 工具许可

  数据采购:   ¥0-50,000（视数据集）
  API调用:    ¥5,000-20,000/月（GPT-4/Claude）
  会议差旅:   ¥5,000-10,000/季度
  工具许可:   ¥2,000-5,000/月
```

## 三、业务价值计算

### 3.1 成本节省型价值

#### 推理成本节省

```
推理成本节省 = (优化前成本 - 优化后成本) × 月调用量 × 有效月数

示例（KV Cache 量化）:
  优化前:  $2.0 / 1M tokens
  优化后:  $1.2 / 1M tokens（KV 显存减半→并发翻倍→单卡成本降40%）
  月调用量: 500M tokens/月
  有效月数: 12个月
  
  节省 = ($2.0 - $1.2) × 500 × 12 = $4,800 = ¥34,560
```

#### 硬件成本节省

```
硬件节省 = (优化前GPU数 - 优化后GPU数) × 单卡成本 × 月数

示例（4-bit量化替代FP16）:
  优化前: 16 × H100
  优化后: 8 × H100（显存减半→卡数减半）
  月数: 12个月
  
  节省 = (16-8) × 15000 × 12 = ¥1,440,000
```

### 3.2 收入增长型价值

#### 性能提升带来收入

```
收入增长 = (优化后QPS - 优化前QPS) × 单请求价值 × 月数

示例（延迟降低33%）:
  优化前: 100 QPS
  优化后: 150 QPS（延迟降→并发升）
  单请求价值: ¥0.05
  月数: 12个月
  
  增长 = (150-100) × 0.05 × 86400 × 30 × 12 = ¥77,760,000
```

#### 用户留存提升

```
留存价值 = (优化后留存率 - 优化前留存率) × MAU × ARPU × 月数

示例（响应速度提升→留存+2%）:
  留存提升: 2%
  MAU: 1,000,000
  ARPU: ¥10/月
  月数: 12
  
  价值 = 2% × 1,000,000 × 10 × 12 = ¥2,400,000
```

## 七、快速计算器

### 7.1 一行估算

```python
# 快速 ROI 估算
def quick_roi(gpu_months, people_months, value_yuan, gpu_type='H100'):
    gpu_cost = {'H100': 15000, 'A100': 8000, 'L40S': 4000}
    cost = gpu_months * gpu_cost[gpu_type] + people_months * 25000  # 平均人月
    roi = (value_yuan - cost) / cost * 100
    return {
        'cost': cost,
        'value': value_yuan,
        'roi': roi,
        'payback_months': cost / (value_yuan / 12) if value_yuan > 0 else float('inf'),
    }

# 示例
result = quick_roi(gpu_months=20, people_months=6, value_yuan=1500000)
print(f"成本: ¥{result['cost']:,}")
print(f"价值: ¥{result['value']:,}")
print(f"ROI: {result['roi']:.0f}%")
print(f"回本: {result['payback_months']:.1f} 月")
```

## 八、常见误区

### 误区 1: 只算 GPU 不算人
❌ ROI = (价值 - GPU成本) / GPU成本
✅ ROI = (价值 - GPU成本 - 人力成本 - 其他) / 总成本

### 误区 2: 用乐观价值
❌ 用"收入增长 7700万"（置信度 30%）
✅ 用"保守价值 147万"（置信度 90%+）

### 误区 3: 忽略时间折现
❌ 把 12 个月后的价值等价于现在
✅ 用折现率（10%/季度）折算

### 误区 4: 不做敏感性
❌ 只算一个 ROI 数字
✅ 做"如果效果减半，ROI 还正吗？"

### 误区 5: 忽略机会成本
❌ 做 ROI=50% 的课题觉得"正收益"
✅ 对比"同样的资源投到 ROI=300% 的课题"
