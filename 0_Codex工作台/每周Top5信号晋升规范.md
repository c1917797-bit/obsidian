# 每周 Top5 信号晋升规范

> 目的：避免信号堆积、防止低质量/无证据内容进入正式洞察层。每周只晋升 **Top 5**，且必须留痕说明淘汰原因。

## 流程（固定顺序）

1. **rank**：`inference-radar.ps1 rank` 按 overall_score 排序本周候选。
2. **shortlist**：`inference-radar.ps1 shortlist` 产出前 10 候选。
3. **人工确认**：从 shortlist 里挑 ≤5 篇，核对 [[必检论文核验清单]] 的关键字段。
4. **晋升**：确认后从 `_候选/` 移到 `4_AI情报洞察/` 对应洞察目录。
5. **留痕**：记录"为什么其他信号被淘汰"，写进本周晋升记录。

## 淘汰必须写明的原因（四选一）

| 淘汰原因 | 说明 |
|---|---|
| 证据不足 | `evidence_score < 2` 或一手来源缺失/无法核验 |
| 收益上限不足 | 命中瓶颈占比 `f` 太小，`f×(1−1/s)` 收益可忽略 |
| 重复已有能力 | 昇腾栈/现网已有等价实现（如 PagedAttention/FlashAttention） |
| 待观察 | 有价值但时间太新/缺代码，转入观察名单下周期再评 |

## 晋升记录模板

```markdown
## 2026-Wxx 信号晋升（晋升 N 篇）

### 晋升
- [[信号A]]：理由（命中瓶颈/收益/源码）

### 淘汰
- [[信号B]]：证据不足（无源码/无实测数字）
- [[信号C]]：重复已有能力（昇腾已内置）
```

## 约束

- 不晋升 `evidence_score=0` 的报告（质量门禁已拦截，见 [[质量看守/使用说明]]）。
- 晋升≠自动归档：晋升后仍需人工按 [[📋_目录导航]] 归到正式知识层。
