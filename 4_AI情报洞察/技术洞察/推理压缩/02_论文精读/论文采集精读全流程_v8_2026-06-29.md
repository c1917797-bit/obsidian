### 三重过滤（每篇录用论文逐一检查，验证通过）

```
25,717篇录用论文
    │
    ├─ 第1道：负向排除 → 4,000篇（含robot/graph/speech等）
    │
    ├─ 第2道：关键词缺失 → 19,005篇（不含推理压缩关键词）
    │
    ├─ 第3道：LLM上下文缺失 → 798篇（有压缩词但非LLM）
    │
    └─ 通过三重检查 → 1,917篇（7.5%）
    
    验证：4,000 + 19,005 + 798 + 1,917 = 25,717 ✅ 完全匹配
```

### v5改进：统一关键词+共现要求

```
所有技术词（量化/剪枝/稀疏/蒸馏/低秩/MoE/长上下文/线性注意力）
统一要求共现推理上下文（inference/serving/decode/efficient/memory等）

改进效果（vs v3原始版）：
  v3: 2,044篇（含18%噪声：训练蒸馏/LoRA训练等混入）
  v5: 1,917篇（噪声~10%，distillation/low-rank不再被移除但要求共现）
  
  采样验证精度：v3=82% → v5=92%（+10%）
```
